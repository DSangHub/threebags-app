# threebags.app

Extra checked bag subscription for domestic and international travel.

## Pages
- `index.html` — Main landing page
- `waitlist.html` — Join the waiting list (Name, Email, Preferred City of Departure)
- `submit-proof.html` — Submit ticket + boarding pass proof for non-participating airline reimbursement

## Features
- Yearly subscription: $49.95 (2 trips) or $99.95 (unlimited)
- Turns 1-bag allowance into 2, or 2 into 3
- Zip-sealed bags, optional delayed delivery (50 mi domestic / 200 mi international)
- Optional baggage insurance ($19.95/bag, max $500)
- Non-participating airline: threebags.app may elect to pay the subscriber directly with valid proof of ticket and boarding pass

Prototype. Airline partnerships required for full prepaid extra-bag flow.
